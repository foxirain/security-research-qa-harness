# Security Policy

Use this project only on systems and repositories you are authorized to test.
Case files are executable specifications and must be reviewed like code before
`--acknowledge-execution-risk` or `--execute` is supplied.

For a vulnerability in this harness, prefer GitHub private vulnerability
reporting. Do not place unpublished vulnerability details, credentials, private
PoCs, or vendor-confidential evidence in a public issue.

The project intentionally does not provide weaponized exploit development,
post-compromise automation, persistence, credential theft, or lateral movement.
Reports about those missing capabilities are outside the security boundary.

See [Publication Safety](docs/PUBLICATION_SAFETY.md) for artifact handling.
