# Report Template

Use this when writing something leadership or an incident manager can consume immediately.

## Executive summary

- We reviewed a report or review summary alleging `[claim]` in `[component]`.
- Current evidence proves `[primitive or impact]`.
- Additional analysis supports `[expanded impact]`.
- The highest defensible impact statement today is `[ceiling]`.
- A stronger claim such as `[RCE / takeover / cross-tenant compromise]` is `[confirmed / supported but unproven / not supported]` because `[reason]`.
